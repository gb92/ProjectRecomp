# Security Policy

## Supported Versions

ProjectRecomp is pre-release software. Security fixes are made only on the
latest `main` revision until formal releases and a version support policy
exist.

## Reporting a Vulnerability

Do not open a public issue for a vulnerability that could expose user data,
execute untrusted code, bypass game-file validation, or otherwise put users at
risk.

Use GitHub's private vulnerability reporting for this repository:

`https://github.com/gb92/ProjectRecomp/security/advisories/new`

Include the affected revision, platform, reproduction steps, impact, and any
suggested mitigation. Do not include copyrighted game files, credentials, or
other sensitive data. A minimal description, hashes, and debugger output are
preferred.

If private vulnerability reporting is unavailable, wait for the repository
owner to provide a private contact method rather than disclosing the issue
publicly.
